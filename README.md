# DungeonSiegeWindowedScripts
A bunch of BAT scripts to run the Dungeon Siege games windowed.

## Installation
Place the BAT file(s) into your game installation directory.

## Usage
Drag-and-drop your game executable onto the BAT, or pass the full path to your game executable as an argument.

If you directly run the BAT, it'll run `DungeonSiege.exe` (or `DungeonSiege2.exe`) by default.
